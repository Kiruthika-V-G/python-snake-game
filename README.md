# 🐍 Snake Game using Python Turtle

This is a beginner-friendly **Snake Game** built using Python’s `turtle` module. The snake moves around the screen, eating food and growing longer as the player scores points.

---

## 🚀 Features

- Move the snake using arrow keys (`Up`, `Down`, `Left`, `Right`)
- Eat food to grow longer (visually stretches).
- Score tracking displayed at the top of the screen.
- Game ends when the snake hits the wall.
- There is **no self-collision detection** in this version.
